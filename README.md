# 通辽可汗式文案创作 Skill

> 本版由 **Kimi K3.1 Pro** 依托 **creator-skill** 生成，比上个版本明显进步，未来仍然继续更新。

一个中文原创文案 Skill：用**高事实密度、短分句连续推进、评书式设问与回扣、冷静陈述荒诞、跨语体反差类比、电影化冷开场和克制收尾**，写出有「小约翰可汗 / 通辽可汗」同类叙事质感的文本。

它学习的是叙事机制，不是复读原句或网络口癖；默认不冒用作者身份，不伪造本人新作。

## 这版做了什么

- 基于 **168 期字幕、约 163.8 万字符、36,757 句**做全量规则扫描，并分层细读不同系列和时期的开头、主体、结尾。
- 把“语感”拆成可执行结构：十一类造句骨架、六种句间衔接、目标→行动→障碍→应对→结果的叙事单元、七类包袱生成器和四类结尾。
- 明确区分早期评书式互动与近期电影化冷开场，不再把固定报家门、三连道别当通用模板。
- 增加分题材工作流：人物/事件、国家/组织、产品/服务、观点/现象，以及改写、压缩和扩写。
- 配套两个 Python 脚本：全语料统计复现和成稿机械风险诊断。
- 设置事实、引语、身份、悲剧降调和商业表达边界，避免为了“像”而编造。

## 安装与使用

把整个目录放入你的 Skill 目录，或使用支持 `.skill` 包的客户端安装打包产物。

触发示例：

- “用小约翰可汗那味儿讲这个人，但不要照抄原句。”
- “把这份资料改成硬核狠人式的口播稿。”
- “用通辽可汗的叙事节奏写一个产品文案，少玩梗。”
- “这篇现象评论要算账、有反差、结尾别升华。”

默认输出中文口播稿；用户指定时，可写短视频脚本、图文故事、人物稿、组织稿、产品稿或评论稿。

## 目录结构

```text
.
├── SKILL.md
├── references/
│   ├── corpus-evidence.md    # 全语料统计、时期与系列变体
│   ├── sentence-engine.md    # 逐句、逐段、包袱和结尾工具箱
│   ├── workflows.md          # 分题材工作流
│   └── examples.md           # 原创迁移示例与正反对照
├── scripts/
│   ├── analyze_corpus.py     # 可复现的字幕统计
│   └── style_lint.py         # 成稿客观诊断，不给虚假相似度分数
├── evals/
│   └── evals.json            # 人物、产品、评论三类试写题目
├── LICENSE
└── 小约翰字幕文本.md          # 原始语料，保留用于研究与复现
```

仓库根目录同时保留上一版的研究资料与测试文件，作为版本对照；当前 Skill 只读取上方列出的新版文件。

## 脚本

```bash
# 统计字幕语料，输出 summary.json 与 episode-metrics.csv
python scripts/analyze_corpus.py 小约翰字幕文本.md --output-dir corpus-analysis

# 诊断一篇 UTF-8 草稿
python scripts/style_lint.py draft.md
```

`style_lint.py` 只检查可量化的机械风险，例如句长、疑问密度、中文数字、连接词、口癖和作文腔；它不判断事实真伪，也不提供“相似度评分”。

## 数据说明

语料来自附件中的 168 期 B 站字幕，覆盖硬核狠人 83 期、神奇组织 40 期、奇葩小国 45 期。字幕包含 AI 转写错误、歌词、漏标点、同人名异写和口播广告，因此统计只用于风格校准，不作为史实来源。仓库保留原始字幕，便于复现与后续版本对比。

## 边界

- 不冒充“小约翰可汗”本人，不伪造其新作。
- 不把情境化对话当真实引语，不杜撰数字、事件、销量、专家背书或用户见证。
- 不消费真实苦难，不对遇难者、弱势群体和悲剧强行玩梗。
- 不用于学术论文、公文、新闻通稿和纯数据播报。
- 不输出针对现实国家、民族、宗教或群体的攻击。
