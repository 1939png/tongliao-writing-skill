# 小约翰式叙事重写 Skill

这是一个处理**已有中文文案**的提示型技能包：允许重构叙事，保持关键事实、因果和限定，以人物算盘、现实阻力、事实反差与口语评述组织口播。完整人物单集按本用户要求以约一万字规划；局部精修保留原稿85%—115%。它不是模型权重、音色克隆或原作者身份模拟。

## 文件入口

- [SKILL.md](SKILL.md)：修订后的主规则，用户指定人物与时间线优先于材料量。
- [万字长稿与过渡](references/longform-and-flow.md)：开场落名接力、松弛叙述、资料补充与长稿预算。
- [人物实稿校准](references/person-first-calibration.md)：黄仁勋稿逐处诊断、人物全传结构与局部示范；衔接规则以万字长稿参考为准。
- [词汇与语气](references/voice-and-lexicon.md)：常用转接、歇后语、历史别称与ASR区分。
- [风格分析报告](references/style-analysis.md)：语料范围、叙述者、结构、句法、幽默、系列与时期差异。
- [写作机制](references/writing-mechanics.md)：17组可操作手法与防过用规则。
- [原创校准样例](references/calibration-examples.md)：人物/机制、组织、地理背景和普通顺利项目四组前后对照。
- [短引文证据](references/evidence.md)：22条短引文、视频身份、原文行号与body字符偏移。
- [阅读覆盖](references/reading-coverage.md)：168篇程序扫描与28篇分层段落细读的区分。
- [语料索引](references/corpus-index.md)：168期标题、日期、系列和原文定位。
- [语义核对](references/semantic-review.md)：事实守恒人工检查与数字保留但含义错误的负例。

## 安装到支持 Skills 的工具

将整个 `xiaoyuehan-rewriter` 文件夹放进工具识别的技能目录，保持 `SKILL.md`、`references/`、`scripts/` 的相对位置不变。常见项目目录为 `.agents/skills/` 或 `.claude/skills/`，以实际宿主配置为准，不要同时在多个会被重复扫描的位置安装相同技能。

本次已在当前工作区的 `.agents/skills/xiaoyuehan-rewriter/` 放置项目副本，宿主已在会话技能目录中发现它，并已通过技能工具成功加载。其他工具若未立即显示，需要刷新技能索引或新建会话。本次未改全局用户技能目录。

支持直接指令加载时，告诉模型读取本文件夹的 `SKILL.md`，再按其中指向加载写作机制。没有技能系统时，也可以在普通对话里上传主技能、写作机制和校准样例，明确要求按文件规则重写。

## 直接使用

```text
使用 xiaoyuehan-rewriter，把下面的材料做成约一万字人物单集。
以其生平为主线，开场事件末端落到人物，下一段自然接身世；
允许补充可靠资料，先核关键事实与待核说法，不编事件和对白；
重要经历展开成过程，不要写成每段一个年份的新闻综述；
具体转接、歇后语和已有别称按语境使用，保持自然讲述。
输出正文，来源与真实待核项集中附后。

【原稿】
……
```

只精修现有段落时，明确写“局部精修，不补材料，篇幅保持原稿±15%”；这与万字单集模式分开。只想拿成稿时，加上“只输出正文”。想收敛语言时，明确写“减少粗口，保留反差和口语节奏”。默认不会自行添加广告、个人使用体验、频道自我介绍或平台互动。

原稿中的品牌、广告或引用若本来就是保留对象，明确说明；不要为了满足篇幅把删去的广告用无关故事补回来。超长原稿可分段处理，先统一事实表、人物简称、主线和结尾，再逐段重写，最后按全稿核对，避免每段独立制造开头和结尾。

## 检查改稿

把原稿和成稿分别保存为纯正文文本，再从本技能目录执行：

```sh
python scripts/check_rewrite.py --source 原稿.txt --rewrite 成稿.txt
```

可选事实锚点文件为JSON字符串数组，例如 `['约20人']` 应写成标准JSON的双引号形式。脚本只检查字面出现与篇幅，不声称验证全部事实和因果。

```sh
python scripts/check_rewrite.py --source 原稿.txt --rewrite 成稿.txt --anchors tests/cases/warehouse/anchors.json
python -m unittest discover -s tests -p test_check_rewrite.py -v
```

第二个命令运行检查器回归测试。第一个带锚点命令仅演示参数：真实原稿应提供它自己的锚点，不应复用货梯测试的数字。

返回码：`0`为篇幅与给定字面锚点均通过，`1`为某项未通过，`2`为输入读取或格式错误。输出注明计数范围；纯正文外的标题、提示和校验附注应由使用者先分离。

## 复核语料依据

包内不附179万字符字幕正文。已有原附件时，可执行：

```sh
python scripts/audit_corpus.py --source "小约翰字幕文本.md"
```

脚本检查附件SHA256、168篇解析、字数、34个字面项与22条引文定位。统计含广告、影视片段和歌曲转写；没有将其伪装成去污染后的净词频，也没有据字幕推算语速和音色。
