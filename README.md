# 通辽可汗式文案创作 Skill

> 本版由 Kimi K3.1 Pro 依托 creator-skill 生成，比上个版本明显进步，未来仍然继续更新。

这是一个中文原创文案 Skill，用高事实密度、短分句连续推进、评书式设问与回扣、冷静陈述荒诞、跨语体反差类比、电影化冷开场和克制收尾，写出有「小约翰可汗 / 通辽可汗」同类叙事质感的文本。

它学的是叙事机制。原句、固定报家门和三连口号不作为模仿目标，默认也不冒用作者身份，不伪造本人新作。

仓库里放着 Skill 本体、SKILL.md、四份参考文档、两段 Python 脚本、三类评测题和 168 期原始字幕。SKILL.md 说明何时触发、写作前读什么、怎样搭事实链和做检查，references 分别处理语料证据、逐句工具、题材工作流和正反示例，scripts 用来复现统计和检查成稿的机械风险。

适合写历史人物、国家与组织、产品和服务、社会现象，也适合把一份资料改成有画面、有转折、有冷幽默的口播稿。默认输出中文口播稿，用户指定时可写短视频脚本、图文故事、人物稿、组织稿、产品稿或评论稿。

## 核心写法

主线是具体事实推进，随后用白话解释本质，再用反差类比或冷判断落点，然后接回新事实。长稿按冷开场、锁定主题、必要背景、前史与动机、初次行动、两到四轮升级、高潮与结局、影响与回扣展开。转折来自材料，不靠随机插入“没想到”。

句子以短分句承载单个动作，用逗号把相关动作连成中长句，句号落在动作链或判断完成之后。短句留给回答、反转、关键事实和停顿。数字按绝对值、熟悉参照、实际影响三步写，类比只比较同一个维度。统计值是诊断参考，不拿来凑句长和数字比例。

幽默优先来自事实本身的荒诞、预期反转、规模或身份错位、克制重新定性和前文回扣。网络梗、绰号和固定口癖只做少量点缀，包袱落地后继续讲事，不解释笑点。

## 这版做了什么

- 基于 168 期字幕、约 163.8 万字符、36,757 句做全量规则扫描，并分层细读不同系列和时期的开头、主体、结尾。
- 把语感拆成可执行结构：十一类造句骨架、六种句间衔接、目标→行动→障碍→应对→结果的叙事单元、七类包袱生成器和四类结尾。
- 明确区分早期评书式互动与近期电影化冷开场，不再把固定报家门、三连道别当通用模板。
- 增加分题材工作流：人物与事件、国家与组织、产品与服务、观点与现象，以及改写、压缩和扩写。
- 配套两个 Python 脚本：全语料统计复现和成稿机械风险诊断。
- 设置事实、引语、身份、悲剧降调和商业表达边界，避免为了像而编造。

## 安装与使用

把整个目录放入你的 Skill 目录，或使用支持 `.skill` 包的客户端安装打包产物。

触发示例：

- “用小约翰可汗那味儿讲这个人，但不要照抄原句。”
- “把这份资料改成硬核狠人式的口播稿。”
- “用通辽可汗的叙事节奏写一个产品文案，少玩梗。”
- “这篇现象评论要算账、有反差、结尾别升华。”

默认输出中文口播稿；用户指定时，可写短视频脚本、图文故事、人物稿、组织稿、产品稿或评论稿。

实际使用时，先读 `references/sentence-engine.md` 选句式和衔接，再按题材打开 `references/workflows.md` 的对应一节。需要核对统计或早晚期差异时看 `references/corpus-evidence.md`，成稿偏营销腔时对照 `references/examples.md`。

## 目录结构

```text
.
├── SKILL.md
├── references/
│   ├── corpus-evidence.md    # 全语料统计、时期与系列变体
│   ├── sentence-engine.md    # 逐句、逐段、包袱和结尾工具箱
│   ├── workflows.md          # 分题材工作流
│   └── examples.md           # 原创迁移示例与正反对照
├── scripts/
│   ├── analyze_corpus.py     # 可复现的字幕统计
│   └── style_lint.py         # 成稿客观诊断，不给虚假相似度分数
├── evals/
│   └── evals.json            # 人物、产品、评论三类试写题目
├── LICENSE
└── 小约翰字幕文本.md          # 原始语料，保留用于研究与复现
```

仓库根目录同时保留上一版的研究资料与测试文件，作为版本对照；当前 Skill 只读取上方列出的新版文件。

## 脚本

```bash
# 统计字幕语料，输出 summary.json 与 episode-metrics.csv
python scripts/analyze_corpus.py 小约翰字幕文本.md --output-dir corpus-analysis

# 诊断一篇 UTF-8 草稿
python scripts/style_lint.py draft.md
```

`style_lint.py` 只检查可量化的机械风险，例如句长、疑问密度、中文数字、连接词、口癖和作文腔；它不判断事实真伪，也不提供“相似度评分”。

## 数据说明

语料来自附件中的 168 期 B 站字幕，覆盖硬核狠人 83 期、神奇组织 40 期、奇葩小国 45 期。字幕包含 AI 转写错误、歌词、漏标点、同人名异写和口播广告，因此统计只用于风格校准，不作为史实来源。仓库保留原始字幕，便于复现与后续版本对比。

## 边界

- 不冒充“小约翰可汗”本人，不伪造其新作。
- 不把情境化对话当真实引语，不杜撰数字、事件、销量、专家背书或用户见证。
- 不消费真实苦难，不对遇难者、弱势群体和悲剧强行玩梗。
- 不用于学术论文、公文、新闻通稿和纯数据播报。
- 不输出针对现实国家、民族、宗教或群体的攻击。
