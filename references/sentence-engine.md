## 1. 三条总原则

1. **事实先于评价**：读者先看懂发生了什么，再听旁白怎么定性。
2. **新信息先于修辞**：一句修辞如果不能补充画面、因果、规模、反差或情绪，就应让位给事实。
3. **落点先于口癖**：包袱落在最精确的词上，不依赖“离谱、狠人、属于是”救场。

## 2. 十一类造句骨架

### 2.1 场景锚定句

**用途**：冷开场、切章节、重返现场。

**骨架**：

> 精确时间 + 地点 + 人物 + 正在做的普通动作 + 异常细节。

**原创示范**：

> 1996 年 4 月 12 日凌晨，港口值班员正给第三艘货船登记吃水深度，直到他发现申报单上的两百台冰箱，总重量还不到一台冰箱。

检查：时间和环境是否影响后续？若不影响，删掉多余天气和氛围。

### 2.2 人物落地句

**骨架**：

> 出生/来历 + 家庭或教育 + 职业路径 + 可验证特点 + 旁白定性。

先写“做过什么”，再写“是什么人”。不要用“传奇、伟大、天才”替代履历。

### 2.3 动作推进句

**骨架**：

> 目标 + 行动 + 方法/工具 + 直接结果。

优先使用可画面的动词：拆、挖、借、凑、改、藏、拖、绕、卖、封、追。避免连续使用“进行、开展、实施、推进”。

### 2.4 制度解释句

**骨架**：

> 表面怪象 + 当时条件 + 激励/限制 + 必然或高概率结果 + 白话翻译。

它回答“为什么这件事在当时不是完全不可理解”。解释不等于替错误行为开脱。

### 2.5 数字换算句

**骨架**：

> 绝对值 + 同维度参照 + 对人物/事件的影响。

**原创示范**：

> 全厂一年只能生产 420 套零件，大概相当于下游车间三天的用量，靠它供应整条流水线，跟拿水杯给游泳池补水差不多。

检查：比较的是否都是产量/时间？不要把面积类比成人口、价格类比成质量。

### 2.6 让步反转句

**骨架**：

> 先承认 A 的部分合理 + 但/结果 + 新事实 B 推翻主要期待。

A 要足够有道理，B 要足够具体。反转的力量来自信息，不来自“万万没想到”。

### 2.7 谦抑升级句

**骨架**：

> 不说是正面评价 A 吧 + 至少也可以说是反向评价 B。

它适合已经有充分事实铺垫的段尾。短稿至多偶尔一处，不能每段复读。

### 2.8 合理但致命瑕疵句

**骨架**：

> 这个方案在逻辑上很完整 + 只有一个问题 + 该问题恰好让方案失效。

“失效原因”可以是对象不存在、时间冲突、无人执行、成本倒挂、权责空白。不要只写“唯一的问题是不现实”。

### 2.9 大词小用与语体错位句

**骨架 A**：

> 本着某崇高原则 + 做一件琐碎、寒酸或自私的具体事情。

**骨架 B**：

> 名义上/理论上/物理上/从某种意义上 + 重新命名真实处境。

语体错位必须让读者一眼看出两个层面为何不相称。不能借大词掩盖事实不清。

### 2.10 设问—短答—解释句组

**骨架**：

> 当前自然会问的问题？短答。下一段立即给证据。

好问题：钱从哪来、为什么没人管、他怎样绕开检查、这个组织靠什么运转。

坏问题：我们是否应该深思、人生意义是什么、你悟到了什么。

### 2.11 对话重演句组

**骨架**：

> 动作/神态 + 短台词 + 对方回应 + 旁白补信息或落点。

台词只保留人物此刻知道的信息，不能让人物提前说出后世结论。没有逐字来源时用间接引语，或明确标为情境化改写。

## 3. 句内节奏与朗读

### 3.1 分句短，句号晚

把一句拆成“动作一，动作二，补充条件，结果”四块，每块通常是一个容易朗读的小分句。不要为了显得硬核塞入多个长定语。

**不顺**：

> 作为一个在当时由于缺乏足够资金以及可靠技术而始终没有办法完成扩建计划的小工厂的管理者，他决定……

**调整**：

> 这家小工厂没钱，也缺技术，扩建计划拖了两年。作为厂长，他决定……

### 3.2 短句只砸关键点

短句适合：

- 回答设问；
- 揭示真正原因；
- 反转最后落锤；
- 悲剧或高潮后的停顿。

连续使用短句会把评书节奏变成鸡汤节奏。

### 3.3 朗读检查

- 一口气能否说完主要分句链？
- 主语是否在中途偷偷换掉？
- 数字、外国名字和长机构名能否读顺？
- 包袱前是否有铺垫，包袱后是否及时停止？

## 4. 句间衔接

### 4.1 结果 → 原因

> 先给反常结果 → 读者产生疑问 → 补制度/背景 → 回到主线。

### 4.2 行动 → 障碍

> 主人公开始行动 → 出现具体障碍 → 改变方法 → 产生新结果。

### 4.3 数字 → 体感

> 给绝对值 → 换成熟悉参照 → 写它对人的实际影响。

### 4.4 支线 → 主线

> 插入必要前史 → 用“这套制度/这个人/这个决定”承接 → 回到当前事件。

支线长度以能解释主线为限，不因为资料有趣就另开一篇。

### 4.5 前文 → 回扣

> 前文埋一个小细节 → 后文让它产生新意义 → 点一次即可。

回扣是“原来如此”，不是重复“还记得吗”五次。

## 5. 段落叙事单元

### 5.1 标准单元

1. 目标：人物现在要什么。
2. 行动：做了什么。
3. 障碍：谁或什么阻止他。
4. 应对：用了什么办法。
5. 结果：成功/失败及其后果。
6. 可选落点：解释、类比、定性或停顿。

### 5.2 三种合法变体

- **事实解释段**：现象 → 数据 → 原因 → 白话总结，可无笑点。
- **高潮段**：动作与结果连续推进，删掉旁白，让冲突自己加速。
- **严肃段**：人物处境 → 选择 → 代价 → 克制判断，不强加梗。

### 5.3 删除标准

一段若只有“非常传奇、十分离谱、令人震惊”，没有新增事实，整段重写。若两句表达同一判断，只保留更具体的一句。

## 6. 开场方法

### 6.1 日期现场型

最适合有明确事件记录的人物/组织稿。用普通动作与异常碰撞，不先讲主题大道理。

### 6.2 结果倒挂型

先给最终结果，再回到起点。结果必须具体，如“图书馆收到一封归还通知，距离借书日已经过去 71 年”。

### 6.3 流行文化引子型

用读者熟悉的作品建立规则，再说现实案例如何突破规则。没有真实作品依据时不捏造电影、游戏或台词。

### 6.4 一句定调型

“这是一个关于 X 的故事”之后，必须立刻用具体事件解释 X。X 最好是可贯穿全篇的具体概念，如“成本”“误会”“退路”，而非空泛“人性”。

### 6.5 产品/现象冷开场

从使用场景、账单、排队、故障或冲突开始，不虚构历史年份来伪装纪录片。

## 7. 包袱生成器

### 7.1 冷静陈述荒诞

做法：删掉“太搞笑了”，只保留最有反差的事实顺序。

### 7.2 规模错位

检查两边是否悬殊：投入与收益、目标与执行、组织规模与实际能力、罪名与动机。

### 7.3 身份/语体错位

让头衔、专业术语或官方表达与真实行为并置。调侃行为和制度，不攻击身份群体。

### 7.4 现代经验类比

可选参照：上班、租房、考试、点外卖、排队、报销、装修、网购售后。

类比格式：

> 当前机制 + 熟悉场景中的同构机制 + 立刻回到主题。

不要为了好笑选择一个逻辑不同的热门梗。

### 7.5 克制重新定性

用“名义上、理论上、至少、从效果上看”等词改变观察角度。措辞越保留，事实越要准确。

### 7.6 俗语与歇后语

只在对象的关键词能自然嵌入时使用。不硬造低俗谐音，不连续堆砌。

### 7.7 回扣

最好的回扣往往不再是玩笑：前面的物件、称号或失败，在结尾变成历史后果或人物命运。

## 8. 对话重演

### 8.1 台词分工

- 人物 A 提供目标或立场；
- 人物 B 提供阻力或信息差；
- 旁白补充双方都不知道的背景；
- 落点来自误解、冲突或结果，而非所有人一起吐槽。

### 8.2 真实性分级

1. **原话**：有可靠逐字来源，可加引号。
2. **意译**：有可靠内容来源，但非逐字，用“他大意是”或间接引语。
3. **情境化改写**：根据事件重构，交付时明确说明。
4. **无依据台词**：删除。

## 9. 结尾方法

### 9.1 事实影响型

> 结局 + 后续制度/传播/行业影响 + 一个具体事实停止。

适合案件、组织、产品和制度故事。

### 9.2 意象回扣型

> 回到开场物件/现场 + 它的新状态 + 与前文形成对照。

适合有核心物件或空间的故事。不要再补一段抽象解释。

### 9.3 人物命运型

> 人物最后处境 + 选择/自述/他人记忆 + 克制判断。

适合悲剧、失败者、坚持者。可以抒情，但必须有具体人物和事实支撑。

### 9.4 标签排比/留钩型

> 把全篇多个事件用同一标准串联 + 得出最后判断；或引出下一篇真实存在的问题。

适合系列稿，非每篇必需，不默认使用固定三连口号。

## 10. 常见失败与修正

| 失败 | 修正 |
|---|---|
| 口癖很多但不像 | 删口癖，补动作、数字、因果与真实转折 |
| 每句都很短 | 把同一动作链的分句合并，短句只留落点 |
| 每句都很长且拗口 | 拆长定语，保留短分句，不拆散所有动作链 |
| 开头背景太多 | 从异常现场开始，把背景挪到读者产生疑问之后 |
| 反转靠“没想到” | 在反转前建立正常预期，反转后给具体新事实 |
| 数字很多仍无感 | 加同维度参照和实际影响 |
| 类比很热闹但不准确 | 只保留机制相同的一点，删除其余联想 |
| 所有角色一个声音 | 按目标、知识、身份和处境重写台词 |
| 悲剧也强行玩梗 | 删除调侃，让事实、选择和代价承担情绪 |
| 结尾突然作文腔 | 回到具体人物、物件、影响或后续事实 |
| 像作者本人新视频 | 去掉本人自称、固定三连和原作复刻句 |
