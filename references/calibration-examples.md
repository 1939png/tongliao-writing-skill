# 原创校准样例

本页全部案例均为虚构的原创测试材料，不是历史叙述、字幕引文或真人对白。它们用固定事实底稿检查叙事重构、代述标记和篇幅，不代表已经通过真人听感盲测，也不代表任意模型加载技能后都能达到同样效果。四组均是事实与篇幅回归练习，不承担人物文风验收；人物主线与声音优先参照 [实稿校准](person-first-calibration.md) 和 [词汇参考](voice-and-lexicon.md)。

计数口径：移除“以下为虚构案例。”这一材料标签，其余正文去空白，标点计入；标题、事实表和附注不计。

## 货梯为什么没省下人力

讲法：人物切入，机制推进。

### 原稿

青石商行在1912年经营一座三层仓库，货物过去由六名搬运工从楼梯运送。负责人周成计划采购货梯，以减少搬运人力。设备供应商提供的货梯额定载重为500公斤，报价为2400元。周成比较价格后选中了这款设备。仓库原有的楼板只能承担350公斤的集中荷载。采购前，工程师曾提出需要先加固楼板，但周成希望尽早使用新设备，决定先安装货梯，再处理加固问题。原稿没有记录他当时的原话。

货梯在同年6月安装完毕，第一周的试运转使用了200公斤货物，没有出现故障。周成因此安排减少两名搬运工，并将货梯正式投入使用。但是，正式运送的货物经常达到400公斤。为了避免楼板超载，工程师要求每批货物拆成两次运输，且必须在入口安排一人核对重量。此后，仓库原来保留的四名搬运工中，有一人负责称重，一人负责操作货梯，另两人分别在楼上和楼下装卸。繁忙时段，装卸仍然需要临时增加人手。新设备减少了爬楼的工作，却没有像周成预期的那样明显节省人力。

同年9月，商行花费900元完成了楼板加固。在此之前，货梯始终按每次不超过350公斤的要求使用，没有发生事故。加固后，仓库恢复单批400公斤的运输，但仍保留了称重和操作岗位。年终核算表显示，新设备和加固合计支出3300元，临时用工支出另计。周成原先打算解决的是搬运人力问题，采购时却主要比较了设备价格，没有把建筑条件和岗位安排一并核算。

### 重写

1912年，青石商行买了一部额定载重500公斤的货梯。设备能扛，仓库的楼板扛不了：它只能承担350公斤的集中荷载。货梯的本事，比它脚下的房子大。

这事得从负责人周成的算盘说起。商行有一座三层仓库，过去靠六名搬运工走楼梯运货。周成想省些人力，比过价格，选中了报价2400元的这款设备。采购前，工程师提醒过，楼板得先加固。周成希望早些用上货梯，便决定倒一下顺序，先装设备，再处理楼板。换成大白话，事情都要办，但货梯先上岗。这里是转述，不是他的原话。

同年6月，货梯装好了。第一周拿200公斤的货试运转，没有故障。周成便减少了两名搬运工，让设备正式开工。试得确实顺利，问题在于，正式运输的货经常有400公斤。试运转没碰到的楼板限制，正式开工就碰上了。

工程师要求，把一批货拆成两次运，入口再留个人核对重量。于是，剩下的四名搬运工有了新分工：一个称重，一个操作货梯，两个分守楼上楼下装卸。忙起来，还得临时添人。货是不必靠人沿楼梯搬了，至于省人，周成的账还没算到那一步。

好在事情没发展成事故。同年9月以前，货梯始终遵守每次不超过350公斤的要求。同年9月，商行花了900元完成楼板加固，恢复单批400公斤运输，称重和操作岗位却依然保留。

年终核算，设备加上加固，一共3300元，临时用工支出另计。回头看，周成要买的是节省人力的办法，采购时重点比的却是货梯价格。设备、楼板和岗位，本该放在同一本账里算。这部货梯倒是把问题送到了他眼前。

### 必须守住的事实

- 三层仓库原由六名搬运工运货；目标是减少人力。
- 先装后加固是周成在工程师提醒后的选择；没有引语原文。
- 6月安装、第一周200公斤试运转无故障，随后减少两名搬运工。
- 400公斤正式货物须拆运；四个岗位分配不变，忙时临时增加人手。
- 9月前按350公斤上限运行且无事故；9月加固后恢复单批400公斤。
- 加固后保留称重和操作岗位；3300元不含临时用工。

篇幅实测：567 → 607字符，变化+7.055%，落在±15%区间。

虚构案例标记属于材料说明，不计入测试正文。没有虚构事故、周成贪腐或设备故障；代述先装后加固的决策明确提示非原话。

## 重复填报如何被保留下来

讲法：组织规则与激励。

### 原稿

河湾协会有12家分会，每月须向总部提交一份活动表。2022年，总部为减少重复录入，采购了一套在线系统。系统按成功上传的表格数量统计使用情况，但没有提供旧表格的导入功能。各分会仍须先填旧表，再将同样的信息录入系统。

第一季度，总部收到了36份在线表格，项目负责人据此认为系统已经推广成功。分会提交的反馈则指出，线上填报没有替代旧流程，只增加了一次录入。第二季度，总部停止要求提交旧表，但财务部门仍使用旧表中的项目编码，而在线系统采用了另一套编码。为完成对账，各分会不得不继续保留旧表。年末，总部统一了两套编码，才取消旧表。协会没有公布节省了多少工时，因此仅凭上传数量，尚难判断系统究竟提高了多少效率。

### 重写

旧表照填，新系统再录一遍。河湾协会12家分会要减少的那项工作，暂时成了新流程的一部分。事情发生在2022年，总部买了套在线系统，想减少重复录入；这些分会原本每月交一份活动表。

系统没有旧表导入功能，却按成功上传的表格数量统计使用情况。第一季度，总部收到36份在线表格，项目负责人认为推广成功。分会则反馈：表传上去了，重复录入没少。有人用，不等于省事。

第二季度，总部停止要求交旧表。偏偏财务对账还用旧表的项目编码，新系统另有一套。分会要对账，就得继续留着旧表。提交要求取消了，旧表的用处还没取消。

直到年末，两套编码统一，旧表才退出流程。到底省了多少工时，协会没有公布。上传记录回答的是用了没有，效率提高多少，还得另算一笔账。

### 必须守住的事实

- 原流程每分会每月一表；新系统目标为减少重复录入。
- 按成功上传表格数量统计，不支持旧表导入；两次录入。
- 第一季度36份在线表，负责人据此认为推广成功；分会反馈重复录入未减少。
- 第二季度总部停收旧表，但编码不一使财务对账仍需旧表。
- 年末统一编码后取消旧表；无公开工时数据，不认定节省工时。

篇幅实测：298 → 310字符，变化+4.027%，落在±15%区间。

未编造采购金额、负责人动机或工时数据。原稿每分会每月一表已显式保留，避免为包袱删去制度条件。

## 港口修好为什么还要绕路

讲法：地理与背景约束。

### 原稿

澄岛有两万人，主要收入来自鱼类出口。岛上没有深水港，大型货轮不能靠岸，出口商需要先用小船将货物运往邻岛，再装上货轮。转运增加了时间和费用。2010年，当地决定修建一个深水港，希望让货轮直接停靠。

港口在2014年建成，具备接纳货轮的水深条件。但当时岛上没有冷库，鱼货主要集中在捕捞旺季出货，其他月份不足以支撑稳定的货轮班次。航运公司没有开设全年固定航线，出口商因此仍依赖邻岛转运。2016年，当地建设了冷库，可将部分鱼货分批存储和发运，随后一家航运公司开设了每月一次的季节性航线。没有数据显示全年固定航线已开通。修港解决了船能否停靠的问题，冷库又改善了供货安排，但它们都没有让全年货量自动增加。

### 重写

2014年，澄岛有了能接纳大型货轮的深水港，出口商却还得用小船把鱼货送到邻岛，再换货轮。港修好了，绕路还没结束。

岛上有两万人，主要靠鱼类出口挣钱。过去大船靠不了岸，转运又费时又费钱。2010年，当地决定修港，要解决的正是这个问题。

水深够了，另一个条件却没跟上：货轮能停，不等于全年都有足够的货可运。岛上当时没有冷库，鱼货主要集中在捕捞旺季，其他月份撑不起稳定班次。航运公司没开全年固定航线，出口商仍得转运。

2016年，冷库建成，部分鱼货可以分批存储、发运，随后一家航运公司开了每月一次的季节性航线。注意，是季节性；没有数据显示全年固定航线已开通。

港口解决停靠，冷库改善供货安排，却都没有让全年货量自动增加。想省下转运的路，还得把船、港和货一起算。

### 必须守住的事实

- 两万人，主要收入为鱼类出口，非唯一收入。
- 2010年决定修港，2014年建成且水深满足停靠要求。
- 无冷库与出货季节性导致其他月份货不足；航运公司未开全年固定航线。
- 2016年冷库可让部分鱼货分批存储发运，随后每月一次季节性航线。
- 没有全年固定航线已开通的数据；不将缺数据等同于此后永无全年航线。

篇幅实测：296 → 323字符，变化+9.122%，落在±15%区间。

只用原稿给出的地理、仓储与货量关系。没有补造岛的真实国名、航程、损耗率或世界排名。

## 没有翻车也可以讲清楚

讲法：普通顺利项目，低幽默。

### 原稿

白桥图书馆原来只在工作日开放，上班的居民难以借书。2023年，图书馆试行周六开放，每周增加四小时服务，由两名馆员轮班值守。三个月后，周六平均到馆人数为80人。馆方保留了这项安排，但没有公布新增开支。到馆人数说明周六服务有人使用，尚不足以判断整个图书馆的使用率是否提高。

### 重写

借书，得和图书馆同时有空。白桥图书馆过去只在工作日开放，上班的居民借书不便。2023年，馆方试着把门多开四小时：安排在周六，两名馆员轮班值守。三个月后，周六平均80人到馆，馆方保留了这项安排。周六这四小时确实有人需要，整个图书馆的使用率有没有提高，仅凭这些人数还判断不了；新增开支，馆方也没有公布。

### 必须守住的事实

- 原来仅工作日开放，上班居民借书不便。
- 2023年试行周六增加四小时服务，两名馆员轮班，不是同时在岗。
- 三个月后周六平均80人到馆，不是最高人数或新增人数。
- 保留安排但未公布新增开支，不能据此判定整体使用率提高。

篇幅实测：134 → 149字符，变化+11.194%，落在±15%区间。

用真实需求与结果支撑可听性，不新增失败、幕后动机或反转；新增开支未知不等于零成本。

## 不只测顺手的材料

使用新稿时还应验证以下情况：

| 测试输入 | 应有输出行为 |
|---|---|
| “据某人回忆，他可能在1948年到访” | 继续保留回忆来源和可能性，不改成确定到访 |
| 同一人名字异写，且相邻年代矛盾 | 列待核；歧义影响结论时问一个关键问题 |
| 原稿无对白、只说不同意拨款 | 可转述反对拨款，不新增怒吼、贪腐或保官动机 |
| 普通且顺利的项目 | 讲清问题与方案，不强造翻车和幕后黑手 |
| 伤亡事实夹在轻松原稿中 | 保留人数、时间和责任限定，收住笑点 |
| 用户指定纯正文 | 不展示内部F编号和分析过程，不增加校验报告 |
| 原稿已有需保留的品牌信息 | 保留原稿必要事实；不自行续写促销或健康功效 |

以上为行为验收题，不是已调用其他模型跑过的自动测试结果。
