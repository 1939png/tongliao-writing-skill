# 人物主线与黄仁勋实稿校准

## 本轮校准范围

用户实测发现，初版技能生成的黄仁勋稿变成了英伟达创业史：童年、求学、工作被压成一段，产品、市值、营收却逐项展开；语言有模板化互动、提前人格评价和反复成功学总结。这个反馈优先于初版微型样例对文风的判断。本页是人物稿的主要校准依据；货梯、表格等小案例只用于事实与篇幅训练。

本轮不主张“原作者从未作主观评价”。语料存在明确评价；真正需要区分的是：事件里的局部讽刺，与替整个人生总结远见、舍得、伟大。用户不喜欢的是后者，以及凭空把普通叙述包装成励志英雄故事。

## 一、逐处诊断

| 实稿片段 | 具体问题 | 修改动作 |
|---|---|---|
| “换一般人……黄仁勋不” | 还没讲完行为，先指定他高于常人 | 去掉普通人对照，直接写联系谁、提出什么要求 |
| “你品品这个要求” | 讲述者给观众发品鉴指令，代替事实落点 | 把履约失败与付款要求并置，让反差成立 |
| “这不叫谈判，这叫耍赖” | 先定性再描述，削掉谈判条件与对方选择 | 先给要求及回应，必要时留一句不升级事实性质的短评 |
| “先认识一下这位老哥” | 模板式介绍口令，切断钩子与生平 | 直接从出生年份、家庭或早年处境接入 |
| “注意这家餐厅，后面还有戏份” | 提前宣布伏笔，把记忆点变成提词 | 首次正常写餐厅，创业再出现时自然唤回 |
| “不值得单开一集” | 用内容价值宣判替代过渡 | 直接进到人物下一个阶段 |
| “第二口井” | 抽象意象先于实际经历，全文被主题隐喻绑住 | 使用具体工作、决定和阶段变化衔接 |
| “赌的是认错/把骂声当路费/舍得” | 给人物的每项行动配成功学品质 | 删除人格总结，把过程和代价留下 |
| 产品与市值逐项列出 | 行文主体从人滑成公司，数字重复证明成功 | 只保留改变人物处境的必要节点，其余压缩或移资料附录 |
| “皮夹克挂在门口” | 可能被误读为实际动作或镜头 | 无依据时改明确修辞，或直接写已证实近况 |

这些词不是全中文永久禁词。它们在这篇里暴露了具体问题，修订时按作用处理，不仅做查找替换。

## 二、选题与材料分布不是同一件事

用户说“写黄仁勋”，目标就是人物。不能因为原稿有大量财报，就自动改判为企业机制稿。

人物全传可按以下顺序组织，实际需要由材料决定：

1. 一个成年阶段的具体难题作短钩子。
2. 开场末端把镜头交到主角，用名字、身份或具体关系连接出生、家庭与迁移，不使用“先认识一下”，也不硬切出生年份。
3. 少年所在环境、求学和早期工作，用具体事件写出这一阶段，不急着证明未来成功。
4. 成年以后按个人经历推进：认识了谁、换了什么工作、如何创业、遇到什么事。
5. 公司背景只解释他当时面对的问题，不独立铺一整部产品年表。
6. 近况与结局限于可靠材料，不用公司行业前景替人物收尾。

“从小到大”是事件时间线，不等于机械每段“某年，他……”。可用一两段解释关系和环境，但读者始终知道主角走到了哪一阶段。

### 黄仁勋稿的材料缺口

用户原稿只用一段承载出生、跨国迁移、教会学校、餐厅打工、大学和两段工作。要写出充分展开的全传，需要增加这些阶段的可靠具体材料，而不是把现有一句扩写成五句性格分析。

尤其需要核对：早期工作先后、家庭迁移的实际安排、学校性质及在校经历、大学与婚姻时间、创业三人如何合作。原稿给出的“先LSI再AMD”本轮不当作已经核实的履历；下方片段绕开该先后。补资料时应回到可靠来源，不将传记常见桥段当事实。

## 三、局部示范：成年钩子接回生平

下列旧片段保留用于查看人物主线，衔接与长稿节奏优先参照 [万字长稿与过渡](longform-and-flow.md)，不要把本片段的压缩节奏继续当完整稿模板。以下是基于用户提供的早年材料作的原创局部校准，展示叙事重心与语气，不是全稿重写，也不宣称已外部核实全部生平。世嘉合约与股权的细节仍按原稿归属表达，未使用后半段现实人物私生活及刑事指控。

> 1996年，黄仁勋遇到了一个很具体的问题：给世嘉做的芯片，交不出来了。
>
> 首款产品NV1卖不动，新项目又选错了架构，按公司后来的说法，账上的钱只够再撑三十天。货交不了，钱也快没了，黄仁勋只好去找客户。他向世嘉方面承认，项目做不下去，得请他们另找一家供应商。不过，事情还没说完：供应商可以换，剩下的钱，还希望照付。
>
> 事情办到这一步，通常该轮到客户追着要钱了，黄仁勋这边却还在申请收钱。按中文媒体后来的复盘，世嘉不仅结了款，还把这笔合约款转成了投资。至于这个让客户另请高明、同时又请客户结账的供应商，是怎么走到这一步的，还得往前倒三十多年。
>
> 1963年，黄仁勋出生于台湾台南。五岁时，他随家人来到泰国曼谷。后来当地局势动荡，父母又安排他和哥哥去美国。九岁的黄仁勋就这样到了肯塔基州的一所教会学校。父母没有立刻同行，两年以后才来到美国，全家后来定居俄勒冈。
>
> 一个孩子，先在台南出生，再到曼谷，接着到了肯塔基，最后才在俄勒冈安顿下来。书还没读完，住的地方倒已经换了好几处。
>
> 十几岁时，黄仁勋在Denny's餐厅打工，端盘子、洗碗，挣些零花钱。再后来，他读完俄勒冈州立大学的电气工程学士，又在斯坦福取得硕士学位。进入半导体行业后，他曾在AMD和LSI Logic工作。此时的黄仁勋，做的是工程师的工作，后来那些发布会、市值和皮夹克，还不是他眼下要操心的事。
>
> 到了1993年，三十岁的黄仁勋和两位来自Sun的工程师克里斯·马拉科夫斯基、柯蒂斯·普里姆，决定一起做图形芯片。他们商量创业的地方，还是Denny's。以前他在这家连锁餐厅打工，后来又坐进它的卡座里筹划新公司，按他自己的说法，启动资金是四万美元。
>
> 三个人看上了个人电脑的多媒体前景，决定做3D图形。只是，方向有了，不等于第一款产品就能卖出去。两年以后，NV1上市，黄仁勋才发现，市场并不打算配合他们选中的那条路线。

### 示范做了什么，没有做什么

- 重点是主语、阶段与衔接，不把它包装成已经完成人物声音盲测的“标准答案”。
- 钩子后的生平直接按年份接入；童年没有被解释成“提前磨炼的企业家意志”。
- Denny's正常出现两次，不喊“注意伏笔”。
- 没有为了加绰号而把苏美领导人拉进来；没有替黄仁勋造一个新庙号。
- 这段语言仍偏克制。完整稿的具体歇后语与混合语体须在充分的人物事件上形成，不靠给每句套成语修复。
- 创业商谈的拍桌、内心独自和双方当场对白均未补造。

## 四、词汇层的实稿验收

给一段约800—1500字的人物叙事做局部校准，比只给十几条抽象原则更有效。检查以下区别：

| 维度 | 未达标 | 应达到 |
|---|---|---|
| 主语 | 产品和营收接连出现 | 人的阶段、关系与行动持续可见 |
| 过渡 | “先认识”“真正主线”“你品品” | 事实直接衔接，或一个具体问题自然引出前因 |
| 评价 | 每步都总结优秀品质 | 大部分让经历说话，局部短评扣事件 |
| 词汇 | 全文只有老哥、离谱，或完全去味 | 具体转接、准确别称、贴题熟语与语体变化 |
| 包袱 | 笑话与事实两张皮 | 说的正是眼前这项处境 |
| 史实 | 代述混成真实引语 | 引语、转述和来源的等级清楚，来源附注不挤正文 |

## 五、这篇后半段的资料状态

用户给稿包含2026年11月关于婚外情、情报关联、董事会罢免和国会作证等重大指控，却未附可核的报道链接或公告原文。技能校准不等于事实背书。本轮不把这些内容继续写成确定新闻，也不据此提炼“陨落英雄”主线。需要先核对媒体原文、英伟达公告和财报日期，再决定整篇结尾能写到哪里。

事实疑点与文风问题分开：即使后半段全获证实，前半段仍然存在人物主线被公司年表替代的问题；即使语言改顺，指控也不会因此自动成立。
