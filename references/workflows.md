# 分题材工作流

> 只读当前题材对应部分。所有题材共用“事实先行、故事推进、反差落点”，但事实类型与幽默边界不同。

## 目录

1. 人物 / 事件稿
2. 国家 / 地区 / 组织稿
3. 产品 / 服务 / 品牌稿
4. 观点 / 现象评论稿
5. 改写已有草稿
6. 长稿压缩与短稿扩写

## 1. 人物 / 事件稿

### 1.1 事实表

优先收集：

- 精确时间、地点和关键现场；
- 出生、家庭、教育、职业与关键关系；
- 每个阶段的目标、资源、行动和结果；
- 金额、数量、距离、刑期、伤亡等有体感的数字；
- 结局、后续影响和可靠引语。

### 1.2 选主线

不要把生平按年份平均分配。先找全篇的核心矛盾，例如：

- 他想做成什么，却一直被什么阻止；
- 他靠什么办法成功，又为什么被同一办法反噬；
- 一个小决定如何逐步变成大事件；
- 外界标签与真实人物有什么差距。

选两至四个能改变人物处境的节点，其余履历压缩成背景。

### 1.3 推荐结构

现场冷开场 → 必要背景 → 人物前史 → 初次尝试 → 连续升级 → 关键高潮 → 结局与影响。

### 1.4 幽默与严肃

- 调侃选择、制度、巧合和认知差，不嘲笑外貌、族群与受害者。
- 悲剧段落停止抖机灵，不用“狠人”消解真实代价。
- 对话没有来源时，用间接引语或标明情境化改写。

## 2. 国家 / 地区 / 组织稿

### 2.1 事实表

- 面积、人口、地理与资源；
- 制度、财政、产业、权力结构；
- 关键年份、政策、领导人与外部关系；
- 政策目标、实际执行和民生后果；
- 同时代参照与后续变化。

### 2.2 先解释机制，再贴标签

不要把国家或组织的问题归结为“全民抽象”“领导有病”。至少回答一个机制问题：

- 资源为什么集中到少数人手里；
- 某项政策为何能通过；
- 为什么没有人纠偏；
- 外部援助或制裁改变了什么激励；
- 统计数字与普通人生活为何不一致。

### 2.3 数字三段式

面积、人口、GDP、财政、产量等，尽量用同维度参照换算。随后写实际影响，例如“这项支出占财政多少”“相当于多少人的年收入”，而不是只比较谁的数字更大。

### 2.4 现实政治边界

历史机制可以分析；当代敏感议题保持中性、可核实，不输出国家或群体攻击，不把地图、民族和宗教当梗。

## 3. 产品 / 服务 / 品牌稿

### 3.1 先确定卖点证据

- 参数、价格、规格、使用条件；
- 真实使用场景与目标用户；
- 和旧方案/同类的同维度比较；
- 适用与不适用边界；
- 可验证的售后、测试或用户反馈。

不把广告台词伪装成历史事实，不虚构销量、检测结果、专家背书或用户体验。

### 3.2 从场景而不是年份开场

可用：

- 早上赶工时遇到的具体故障；
- 一张账单、一段排队、一次搬运；
- 旧方案的麻烦与新方案的动作对照。

不要为模仿历史开场而编造“1923 年，这个品牌……”的品牌故事。

### 3.3 卖点翻译链

> 参数/功能 → 用户动作 → 具体结果 → 同维度类比 → 使用边界。

**原创抽象示范**：

> 双层饭盒容量 1.2 升，上层装菜下层装饭，中午不用把三样东西泡在一起；对带饭的人来说，这不是什么黑科技，只是让番茄炒蛋别再把米饭染成统一色号。

### 3.4 商业表达边界

医疗、保健、金融等题材不夸大效果，不写“包治、稳赚、最有效”。没有依据时不制造紧迫感与虚假稀缺。用户要求硬广时可保留直接行动引导，不必强行留下篇钩子。

## 4. 观点 / 现象评论稿

### 4.1 把观点改成可叙述的问题

不要从“我认为”开始。先找：

- 一个典型场景；
- 一组可核实数据；
- 两个利益或目标冲突；
- 一个反常识机制；
- 一个具体案例的后续结果。

### 4.2 论证结构

场景由头 → 表面解释 → 更深入的成本/激励 → 反例或边界 → 回到场景作结论。

设问必须被证据回答。不要用多个排比句替代论证，也不要把个案夸成全民规律。

### 4.3 幽默落点

优先调侃制度设计、流程荒诞、账本反差和人们心照不宣的行为，不攻击某类人的性别、地域、职业或身份。

## 5. 改写已有草稿

1. 先提取原稿不可丢失的事实、数字、引语和结论。
2. 标出重复评价、空泛形容、无功能背景和作文腔结尾。
3. 重排为“现场→背景→行动→障碍→结果→影响”。
4. 逐句补动作与因果，把长定语改成短分句链。
5. 只在事实错位明显处加一到两个类比，不为每段强行造梗。
6. 与原稿对照，确认没有新增未经提供的“事实”。

交付时默认只给改写稿；用户要求时，再列主要修改点。

## 6. 长稿压缩与短稿扩写

### 压缩

- 保留核心矛盾、关键数字、真实转折和结局；
- 合并同类背景与重复案例；
- 优先删评价和重复梗，不删导致因果断裂的事实；
- 短稿只保留一个主包袱和一个结尾回扣。

### 扩写

- 不用形容词和口癖灌水；
- 补现场、制度背景、行动过程、失败尝试和后续影响；
- 新事实不足时明确说明可扩写空间有限；
- 每增加一个支线，都要用一句话说明它如何解释主线。
